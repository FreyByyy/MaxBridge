# MaxBridge — пересылка из MAX в Telegram

> [!WARNING]
> ## ⚠️ Ваш аккаунт MAX могут заблокировать
>
> **У MAX нет официального API для личных аккаунтов.** Бот входит в ваш аккаунт как ещё одно устройство
> через неофициальный протокол — **это нарушает правила MAX**. Аккаунт могут ограничить или заблокировать
> в любой момент, без предупреждения. После обновлений MAX бот может перестать работать.
>
> **Используйте бота только на свой страх и риск.** Лучше — на отдельном аккаунте MAX, потеря которого
> не страшна. Авторы не отвечают за блокировки и потерю данных.

Бот читает выбранные чаты MAX вашего аккаунта и пересылает сообщения в чаты Telegram.
По желанию сообщения сортируются на **объявления** и **диалоги**, и любой тип можно выключить.
Спорные сообщения решает ИИ (если подключён) или вы — кнопками в личке. Для отдельных чатов
можно включить режим «всё на модерацию».

## Что умеет

- **Только чтение MAX.** Отправка, правка, удаление, реакции и отметки «прочитано» заблокированы
  на уровне соединения (`bot/readonly_guard.py`) — даже ошибка в коде не сможет ничего написать в MAX.
  Сообщения в MAX не отмечаются прочитанными, аккаунт не показывается «в сети».
- **Доступ.** Управляет ботом только владелец (`OWNER_ID`). Владелец назначает доверенных и решает,
  какие чаты MAX каждому из них доступны. Доверенные добавляют бота в любое число своих чатов Telegram
  и выбирают, что туда пересылать. Если бота добавил кто-то другой — бот пишет заданное сообщение и выходит.
- **Формат** как в `msg.md`: имя из профиля MAX, @ник, роль (👔 Админ / ⭕ Владелец), время и дата.
  Ответы показываются цитатой. Если в чат Telegram идут сообщения из нескольких чатов MAX, сверху
  добавляется название чата MAX.
- **Правки и удаления.** Изменили в MAX — бот правит своё сообщение. Удалили — внизу появляется
  **🗑️ Оригинальное сообщение удалено**.
- **Вложения** (фото, видео, голосовые, файлы, стикеры) пересылаются всегда; каждый тип выключается.
  Ограничение Telegram для ботов — 50 МБ на файл; бо́льшие файлы помечаются в тексте.
- **Стоп-слова и стоп-авторы** — такие сообщения не пересылаются никогда, при любых настройках
  (`/stop_add`, `/stop_del`, кнопка «🚫 Автор — никогда» на карточке модерации).
- **Всё на модерацию** — переключатель у каждого чата MAX (📥 Источники MAX → чат). Каждое сообщение
  сначала приходит вам с кнопками «✅ Переслать / ❌ Не пересылать» и уходит в Telegram только после
  «Переслать». Если разделение включено, в карточке есть подсказка классификатора.
- **Разделение на объявления и диалоги** — по умолчанию **выключено**: пересылается всё.
  Включается в меню → 🏷 Классификация. После этого у каждого чата MAX появляются переключатели
  «📢 Объявления» и «💬 Диалоги». Включены оба — классификатор не нужен, пересылается всё.
  Включён только один — работает классификатор. Диалоги можно присылать без звука (🔕).
- **Классификация** (`data/rules.json`):
  - авторы «пересылать всё»;
  - сильные слова (+3), ключевые слова (+1) — совпадение с началом слова;
  - время, дата, день недели, ссылка, несколько строк, «!»;
  - фамилии участников группы (с падежами) и похожие на фамилии слова;
  - автор — админ/владелец группы;
  - минус: слова диалога, ответ на сообщение, очень короткое, вопрос.

  Баллы ≥ 4 — объявление, ≤ 1 — диалог, между — спорное. Пороги меняются командой `/threshold`.
- **Модерация и обучение.** Спорное сообщение приходит вам с кнопками и висит, пока вы не решите.
  После решения бот предлагает добавить слова из сообщения в правила, а само сообщение
  становится примером для ИИ.
- **ИИ** — любой OpenAI-совместимый API (OpenAI, Anthropic, DeepSeek, OpenRouter, Ollama…): `/ai`.
- **Статистика** — `/stats`: сколько сообщений за 7 дней переслано, отброшено, стоп и ждут модерации.
- **Связь с MAX.** Бот пишет о первом подключении, о долгом обрыве (больше 10 минут) и о возвращении
  после обрыва дольше 5 минут. Короткие переподключения, которые MAX делает сам, проходят молча.

## Запуск на сервере

Нужен любой Linux-сервер с Docker (1 ГБ RAM хватает) за пределами РФ.

### Бесплатные варианты

| | Что дают | Карта |
|---|---|---|
| **Google Cloud** e2-micro | 2 vCPU, 1 ГБ, 30 ГБ, только регионы us-west1 / us-central1 / us-east1 | нужна; виртуальные карты принимают не всегда |
| **Oracle Cloud** Always Free | ARM 2 ядра / 12 ГБ | официально **не принимает виртуальные и предоплаченные карты** |

Если карту не примут — подойдёт любой VPS за ~3–5 €/мес (Hetzner, и т.п.).

### Установка

```bash
# 1. Docker (Ubuntu/Debian)
sudo apt update && sudo apt install -y docker.io docker-compose-v2 git
sudo usermod -aG docker $USER   # перелогиньтесь после этого

# 2. Код
git clone https://github.com/FreyByyy/MaxBridge.git
cd MaxBridge

# 3. Настройки
cp .env.example .env
nano .env            # BOT_TOKEN и OWNER_ID обязательны

# 4. Папка для данных (контейнер работает от пользователя с uid 1000)
mkdir -p data && sudo chown 1000:1000 data

# 5. Запуск
docker compose up -d --build
docker compose logs -f
```

Обновление: `git pull && docker compose up -d --build`.

### Первые шаги в Telegram

1. Напишите боту `/start` — откроется меню.
2. `/login` — пришлите телефон, затем код из MAX/SMS (и облачный пароль, если он есть).
   Сообщения с кодом и паролем бот сразу удаляет.
3. Меню → **📥 Источники MAX** — отметьте чаты, которые бот должен читать.
4. Добавьте бота в группу Telegram — он пришлёт в личку кнопку «Выбрать чаты MAX».
5. Доверенные: меню → **👥 Доверенные** → «Добавить», затем отметьте, какие чаты MAX им доступны.

Пересылаются только **новые** сообщения — с момента, когда чат MAX стал источником.

## Файлы данных (`data/`)

- `max/session.db` — сессия MAX. **Даёт доступ к аккаунту**, никому не передавайте.
- `bot.db` — настройки, доступ, связи сообщений (для правок/удалений; хранятся 60 дней).
- `rules.json` — слова, авторы, пороги, примеры. Можно править руками, затем `/reload_rules`.

## Риски

MAX не даёт официального API для личных аккаунтов. Бот входит как ещё одно устройство Android через
неофициальную библиотеку [PyMax](https://github.com/MaxApiTeam/PyMax) (MIT). Это нарушает правила
MAX: аккаунт могут ограничить, а после обновлений MAX протокол может перестать работать — тогда
нужно обновить `maxapi-python` в `requirements.txt`.

## Разработка

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt pytest pytest-asyncio   # Windows
python -m pytest
```
